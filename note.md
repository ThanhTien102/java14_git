# GITHUB

## DEMO GIT
- khởi tạo dự án github với file note.md
- `git --verison` : kiểm tra phiên bản
- `git config --global user.name "your_name"` ( your_name là gì cx dc)
- `git config --global user.email "your_github_email"` (email phải là mail github)
  - lệnh global để cấu hình thông tin chỉ làm 1 lần
- `git init`: khởi tạo sử dụng git cho ự án, mỗi dự án làm 1 lần
- `git remote add origin duong_dan_https`: kết nối folder trong máy với repo online
- Step 1;
    - `git add.` : thêm tất cả các thay đổi để đẩy lên git
    - `git add <ten_file>` : thêm 1 file vào danh sách theo dõi 
- Step 2:
    - `git commit -m 'noit dung comit'`: chụp màn hình code ở thời điểm thao tác  
- Step 3:
    - `git push -u origin <ten_branch`: chạy lần đầu tiên
